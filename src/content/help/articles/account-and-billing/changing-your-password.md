# Changing Your Password

Update your password and manage account security.

## Overview

Regularly updating your password helps keep your financial data secure. ProcessX makes it easy to change your password and manage your account security.

## When to Change Your Password

Consider changing your password if:
- It's been more than 6 months
- You've used the same password elsewhere
- You suspect unauthorized access
- You've shared it with someone
- A data breach is reported

## How to Change Your Password

### Step 1: Navigate to Settings

1. Click your name/avatar in the navigation
2. Select **Settings**
3. Go to **Security** or **Change Password**

### Step 2: Enter Current Password

For security, you must verify your current password.

### Step 3: Enter New Password

Create a strong new password:
- At least 8 characters
- Mix of uppercase and lowercase
- Include numbers
- Include special characters

### Step 4: Confirm New Password

Re-enter your new password to confirm.

### Step 5: Save Changes

Click **Update Password** or **Save**.

You'll receive a confirmation email.

## Password Requirements

ProcessX requires passwords that meet these criteria:

| Requirement | Status |
|-------------|--------|
| Minimum 8 characters | Required |
| Uppercase letter | Required |
| Lowercase letter | Required |
| Number | Required |
| Special character | Recommended |

### Strong Password Examples
- `Tr@vel2025!SA`
- `MyBusiness#2024`
- `Exp3nses@Work`

### Weak Password Examples
- `password123` (too common)
- `12345678` (no letters)
- `business` (too simple)

## Forgot Your Password?

If you've forgotten your password:

1. Go to the login page
2. Click **Forgot Password**
3. Enter your email address
4. Check your email for reset link
5. Click the link (valid for 24 hours)
6. Create a new password
7. Log in with new password

## Password Reset Not Arriving?

If you don't receive the reset email:
- Check your spam/junk folder
- Verify you entered the correct email
- Wait a few minutes and try again
- Contact support if issues persist

## Additional Security

### Two-Factor Authentication (2FA)

Add an extra layer of security:

1. Go to **Settings** > **Security**
2. Enable **Two-Factor Authentication**
3. Scan QR code with authenticator app
4. Enter verification code
5. Save backup codes securely

### Session Management

View and manage active sessions:

1. Go to **Settings** > **Security**
2. View **Active Sessions**
3. Click **Log Out** on unknown devices
4. Click **Log Out All Devices** if concerned

### Login Notifications

Enable alerts for new logins:
- Get notified of new device logins
- See login location and time
- Quickly detect unauthorized access

## Best Practices

1. **Use unique passwords**: Don't reuse passwords across sites
2. **Use a password manager**: Tools like 1Password, LastPass
3. **Enable 2FA**: Adds significant security
4. **Don't share passwords**: Each user should have own account
5. **Update regularly**: Change passwords periodically

## If You Suspect Unauthorized Access

Take immediate action:

1. Change your password immediately
2. Log out all devices
3. Review recent activity
4. Enable 2FA if not already
5. Contact support if data was affected

## Team Member Passwords

If you're an account admin:
- You cannot see team passwords
- You can reset team member access
- You can remove team members
- Each member manages their own password
