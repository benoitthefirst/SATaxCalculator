# Purpose

The homepage is the most important page of the ProcessX website.

It has one objective:

Convert visitors into customers.

Every section must answer a question a potential customer has.

The homepage should feel closer to Stripe, Linear, Mercury, Ramp and OpenAI than traditional accounting software.

# Claude Code Instructions

Build every section as an independent component.

Never hardcode content.

Use content files.

Every section must support animation.

Every image must use next/image.

Every section must be reusable.

Every section must be responsive.

Never duplicate components.

Keep files under 300 lines.

Always use semantic HTML.
