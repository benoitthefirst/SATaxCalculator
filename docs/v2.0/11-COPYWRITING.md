# Purpose

This document defines the messaging for the entire ProcessX marketing website.

Every headline, CTA, paragraph and FAQ must follow this guide.

The objective is simple.

Explain ProcessX in the clearest possible way.

Sell outcomes.

Not software.

# Ultimate Writing Rule

Every sentence should answer one question.

Every section should encourage the next scroll.

The visitor should never wonder:

"What does ProcessX actually do?"

That answer must become clearer with every section.
