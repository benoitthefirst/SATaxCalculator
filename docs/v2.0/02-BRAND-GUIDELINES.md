# ProcessX Brand Guidelines
Version 2.0

---

# Brand Position

ProcessX is not traditional bookkeeping software.

ProcessX is an AI-powered finance platform designed specifically for South African businesses.

The brand should communicate:

• Intelligence
• Trust
• Precision
• Automation
• Professionalism
• Premium Quality
• Innovation

The visual identity should feel closer to Stripe, Linear, Ramp, Mercury and Vercel than to traditional accounting software.

Visual inspiration should be taken from:

• Linear
• Vercel
• Mercury
• Ramp
• Notion
• Arc Browser

# Deliverable Standard

Every new component must feel like it belongs to the same design system.

A visitor should immediately recognise every page as ProcessX without seeing the logo.
