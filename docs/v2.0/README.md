# About ProcessX

ProcessX is an AI-powered bookkeeping platform built specifically for South African businesses.

It helps businesses automate bookkeeping, document processing, tax preparation and financial reporting using artificial intelligence.

Unlike traditional bookkeeping software, ProcessX focuses on eliminating manual data capture by automatically extracting information from business documents.

Examples include:

- Invoices
- Receipts
- Bank Statements
- Payslips
- Expense Reports
- Purchase Orders

ProcessX converts these documents into structured bookkeeping data in under 60 seconds.

# UX Principles

Always show before explaining.

Use screenshots instead of illustrations.

Use real dashboard previews.

Avoid long paragraphs.

Use clear headings.

Every section should answer a question.

Example:

Question

"What does ProcessX process?"

↓

Section

"Everything AI Can Process"

Question

"How does it work?"

↓

Section

"Watch ProcessX Process a Document"

Question

"What does the software look like?"

↓

Section

"Business Dashboard"
